# ISP-Copilot
Inteligencia Artificial y Monitoreo Proactivo para el NOC del futuro

ISP-Copilot es un ecosistema de automatización diseñado para transformar el soporte técnico en los proveedores de servicios de internet. Mediante la integración de Zabbix para la observancia de red y n8n como orquestador de flujos de trabajo, este proyecto despliega un agente de IA capaz de:

* Nivel 1 Autónomo: Responder consultas comunes y realizar diagnósticos básicos de última milla sin intervención humana.

* Asistente NOC: Colaborar con ingenieros de nivel avanzado proporcionando resúmenes de fallas, correlación de alertas y sugerencias de resolución basadas en logs.

* Despliegue Rápido: Configuración optimizada para entornos Linux (Ubuntu) utilizando contenedores para una implementación ágil en infraestructuras ISP.
